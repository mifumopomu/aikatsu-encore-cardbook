# アイカツ！アンコール カード帳

このフォルダは iPhone のホーム画面からアプリのように起動できる Web アプリ版です。

## GitHub Pagesへの公開
1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html`, `manifest.json`, `sw.js`, `icon-180.png`, `icon-192.png`, `icon-512.png` をリポジトリの一番上にアップロードします。
3. GitHubの Settings → Pages で公開元を `main` ブランチ / `/ (root)` に設定します。
4. 数分待つと公開URLが表示されます。
5. iPhoneのSafariでURLを開き、「共有」→「ホーム画面に追加」→「Webアプリとして開く」をON→「追加」。

カード画像は公式サイトの画像URLを参照しています。公式サイト側の仕様変更等により画像が表示されなくなる場合があります。
